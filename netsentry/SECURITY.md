# Security Policy

## Supported scope

This is an educational offline parser, not a production intrusion-detection system.

## Reporting an issue

Please report reproducible parsing errors, unsafe handling of input files, or misleading security claims through GitHub Issues. Do not include private packet captures, credentials, personal data, or other sensitive material in a public issue. For sensitive disclosures, contact the repository maintainer privately through a verified GitHub contact method.

## Safe use

Only analyze packet captures you own or are authorized to handle. Treat all capture files as potentially sensitive.
